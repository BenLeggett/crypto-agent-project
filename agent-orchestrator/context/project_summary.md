This project is the `agent-orchestrator/` layer is a local Python-based development assistant that reads project documentation, builds minimal context packs, generates Codex-ready prompts, posts Discord updates, runs validation checks, and logs progress to `ACTIVITY.md`. The current stack for the orchestrator is Python, SQLite, Discord webhooks, local LLM access through LM Studio’s OpenAI-compatible API, optional cloud model fallback, and manual Codex handoff. Hard constraints: the orchestrator is development-only, must stay isolated from the trading runtime, must not execute trades, must not access or modify exchange credentials, must not touch live configs, and must require human approval for phase transitions, risky files, architecture changes, cloud-extra-high model use, commits, or any future automated Codex execution.
